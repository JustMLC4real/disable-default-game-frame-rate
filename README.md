# Disable Default Game Frame Rate

Keeps Android’s **Disable default frame rate for games** setting enabled after reboot. Requires Magisk and firmware that supports the setting.

## Install

1. [Download the module ZIP](https://github.com/JustMLC4real/disable-default-game-frame-rate/releases/latest).
2. Install through **Magisk → Modules → Install from storage**.
3. Reboot.

Applies once per boot. Does not enable Developer options or bypass a game’s own FPS cap. Turning Developer options off can reset the setting until the next reboot.

Use **Action** in Magisk to view the status. To remove, uninstall in Magisk and reboot.
